# Deployment

- This project deploys through the existing GitHub repository `Ratenne/ravirgo`, branch `main`. The user has connected automatic production deployment to GitHub pushes.
- Do not create, update, or publish a GPT Site / Sites preview unless the user explicitly requests it again.
- Preserve SEO metadata, Naver verification and service URLs already committed on `origin/main`.
- Build with `npm run build`; the static output directory is `dist`. See `docs/deployment.md` for the Git workflow.
