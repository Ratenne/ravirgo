# 서비스 모델 품질 개선

2026-10-15. 공전 경로, 카메라 구도, HTML 이름표, 검색과 서비스 링크를 유지하면서 모델과 렌더러를 개선했습니다.

- `src/scripts/service-models.ts`: PricePulse의 5개 막대에 분리 간격, 부드러운 베벨과 금속 하부 지지면을 적용합니다. 영수증은 양면과 닫힌 옆면을 가진 실제 두께의 곡면 메시이며 인쇄가 UV 텍스처를 따라갑니다. 종이 더미는 공유 지오메트리를 사용합니다. 모델 교체 위치는 이 파일입니다.
- 데스크톱 영수증 한 장: 정점 9,650개, 삼각형 19,296개. 모바일 한 장: 정점 3,842개, 삼각형 7,680개. 인쇄 텍스처는 각각 1024×2048 / 512×1024입니다. 인쇄 숫자는 조형용 예시이며 실제 서비스 데이터가 아닙니다.
- `workbench.ts`: 원형 받침대의 곡면과 모서리, 금속 거칠기·반사와 조명을 조정합니다. 별도의 외부 모델/텍스처 요청은 없습니다.
- `showcase-config.ts`, `orbital.ts`: DPR 상한 2 / 1.5, 후처리 렌더 타깃 MSAA 4× / 2×. MSAA 미지원이면 FXAA를 사용합니다. MSAA 사용 시 FXAA를 중복 적용하지 않습니다. 저메모리 보고 기기는 DPR 1.25 상한입니다.
- 셰이더 초기 24프레임을 제외하고, 30프레임 평균 렌더 제출 시간이 65ms를 넘는 구간이 3회 지속될 때 균형 모드로 낮춥니다. CPU 제출 시간이며 GPU 벤치마크가 아닙니다. 정지 상태는 추가 프레임을 그리지 않습니다.

## 검증

`npm run dev` 이후 `npm test`와 `node qa-model-quality.mjs`를 실행합니다. 후자는 설치된 macOS Chrome을 사용합니다. HiDPI에서 실제 캔버스 해상도, MSAA, 데스크톱↔모바일 리사이즈와 진행률 보존을 검사합니다. 두 품질 프로필의 종이 메시에서 비정상 면적 삼각형·2개 면에 공유되지 않는 모서리·유효하지 않은 법선을 검사했습니다. 모두 0이거나 정상입니다. 이는 자체 교차나 완전한 물리 정확성 검사까지 포함하지 않습니다.

기존 반복·역방향·정지·검색·모델 본체 클릭·HTML 이름표 키보드 이동·모바일 제스처 검사를 통과했습니다. `.impeccable/review/mesh-quality/`에 전후 확대 화면, 데스크톱/모바일 화면과 검사 결과가 있습니다. 실제 휴대전화와 Safari, GPU 메모리·발열은 이번 검사에서 확인하지 않았습니다.
