# 반복 경로 서비스 쇼케이스

2026-10-15. 사용자 요청에 따라 이전 800vh 단일 통과 방식을 교체했습니다.

## 구성과 조정

- `src/scripts/showcase-config.ts`: 공전 중심 `(0,0)`, 반지름 `5.05`, 모델 간격 `8`, 초기 진행률 `.56`, 숨김 구간 `.12`, 한 주기 휠 거리 `viewportHeight × 4`, 드래그 거리 `stageWidth × 1`, 카메라와 품질 설정.
- `src/scripts/showcase-path.ts`: 진입 Bézier → 수평 원 한 바퀴 → 퇴장 Bézier. 각 모델의 지연을 적용한 무제한 입력값을 `1 + cyclePause` 주기로 순환시킵니다. 음수 입력도 같은 경로를 역행합니다.
- `src/scripts/orbital.ts`: 캔버스 휠/가로 드래그, 모델 위치·경계 페이드, 모델 본체와 받침대/이름표 Raycast 클릭, 렌더링과 정리.
- `src/scripts/directory.ts`: 검색·필터, 모션 감소, 3D 토글과 진행률 복원.
- `src/pages/index.astro`, `src/styles/home.css`: 짧은 장면과 바로 이어지는 기본 HTML 서비스 목록.
- 실제 메시 교체 위치는 `src/scripts/service-models.ts`이며 `workbench.ts`가 이를 생성합니다. 현재 외부 GLB 모델은 사용하지 않습니다.

원판 반지름 6.53에서 받침대 반지름 약 1.368을 뺀 범위 내로 궤도를 배치했습니다. 공전 중심과 발광 허브를 원판 중심에 정렬했습니다. 초기 화면에서 두 모델이 공전 중인 위치에 보이며, 입력을 계속하면 각 모델이 퇴장과 다음 진입을 반복합니다. 자동 재생은 없고 입력이 없으면 정지합니다.

검색/필터 UI 및 목록에서는 페이지가 일반적으로 스크롤됩니다. 모바일 가로 스와이프는 경로를 조작하고 세로 스와이프는 페이지를 스크롤합니다. 서비스 목록은 3D 상태와 관계없이 HTML로 제공됩니다. WebGL·모션 감소·데이터 절약 대체 화면과 실제 서비스 링크를 유지합니다.

## 검증

`npm run dev` 후 다른 터미널에서 `npm test`. `npm run build`는 Cloudflare Pages용 `dist/`를 출력합니다.

Chrome 1440×900 및 390×844 모바일 에뮬레이션으로 검사했습니다. `.impeccable/review/loop/results.json`에 반지름, 반복·역방향, 한 바퀴 반시계 방향, 입력 정지, 고정 장면, 목록 기본 노출, 필터 진행률 유지, 두 실제 모델 본체 클릭, 모바일 영수증 본체 탭, 가로 터치와 세로 스크롤, 토글/복원, 앵커 이력, 모션 감소·WebGL 대체 화면의 통과 결과를 저장합니다.

실제 스마트폰/Safari, GPU 발열·메모리, 컨텍스트 복구는 이번 검사에서 확인하지 않았습니다. 개발용 경로는 `?pathDebug=1`로 확인하며 기본 화면에서는 숨깁니다.

## 화면 크기와 HTML 이름표

`wheelViewportHeightsPerCycle`과 `dragStageWidthsPerCycle`이 감도를 설정합니다. 각 입력마다 현재 브라우저 높이/장면 너비를 읽으므로 창 크기 변경 후에도 즉시 적용되며 진행률은 초기화하지 않습니다. 180px 휠 입력을 검사했을 때 높이 900px에서는 진행률 .056, 높이 700px에서는 .072만큼 이동했습니다.

`index.astro`에서 서비스 이름과 URL을 실제 `<a data-model-label>`로 정적 출력합니다. `orbital.ts`는 이름표 위치를 카메라로 투영하고 가림/공전 구간/필터에 맞춰 표시합니다. 캔버스 텍스트 텍스처를 사용하지 않습니다. 이름표는 기본 HTML 링크이므로 키보드 Enter, 링크 주소 복사 등을 사용할 수 있습니다. DOM과 WebGL 자원은 3D 해제 시 함께 정리됩니다.
